⚙️ One-time setup

This version syncs both phones through Firebase. First, create a Firebase project and paste its web configuration below. You only need to do this once before hosting the page.

  1. Open the Firebase Console and create a project.
  2. Add a Web app and copy its Firebase configuration.
  3. In Build → Realtime Database, create a database.
  4. In Authentication → Sign-in method, enable Anonymous.
  5. Paste the config fields below, then tap Save setup.

Firebase web config is not a secret. Protect the database with authenticated rules and add Firebase App Check before sharing widely.
