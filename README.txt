LaBoss Digital Hub — installable PWA starter

BEFORE PUBLISHING
1. Open index.html in a code editor.
2. Find: const WHATSAPP_NUMBER = "2340000000000";
3. Replace the demo number with your own Nigerian number in international format:
   remove the first 0 and add 234, with no + sign or spaces.
   Example only: 08012345678 becomes 2348012345678.
4. Save.

PUBLISH
Upload ALL files and folders from this package to a GitHub repository, keeping the structure intact.
Make sure index.html is in the repository root.
Enable GitHub Pages in Settings > Pages and publish from the main branch and root folder.
PWA installation and service workers require HTTPS hosting.

INSTALL ON ANDROID
Open the published HTTPS website in Chrome. Tap the three-dot menu and choose Install app or Add to Home screen.

NOTES
This is a static website, not a database-backed admin system. WhatsApp orders require internet and the site does not process card payments. Basic site files are cached for offline viewing; WhatsApp still needs internet.
